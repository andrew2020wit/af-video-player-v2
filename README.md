# AF Video Player

A video player whose main feature is showing all subtitles at once in two columns:
the subtitles in the original language and the subtitles of the translation.

Because all subtitles are shown at once, they have to be in external files.
The player can also export embedded subtitles to external files.

**[Screenshots](SCREENSHOTS.md)**

It is free software built only on open source technologies and
libraries. Target platforms: Windows, Linux and macOS.

## Idea

- Subtitles do not get in the way while you watch.
- `Space` pauses the video and shows the whole list of cues in a column: the current cue in the centre, next to it
  the translation from a second subtitle file.
- A click on a word opens an online dictionary, a button next to a cue opens Google Translate.
- A click on the time of a cue jumps to that moment of the video.
- The player remembers the playback position, audio track and subtitles of recent files.

## Features

- Playback through [libmpv](https://mpv.io/): a wide range of video and audio formats (MKV, HEVC, AC3/DTS, …).
- Choice of the audio track, remembered for each file.
- External subtitles in SRT, VTT and ASS/SSA; automatic search for subtitle files next to the video.
- Export of embedded text subtitles to external files.
- Opening files from the history, from the file manager, by drag & drop and from the command line.

## Technologies

C++20, [Qt 6](https://www.qt.io/) / QML, [libmpv](https://mpv.io/) for playback and
[FFmpeg](https://ffmpeg.org/) for extracting embedded subtitles.

## Usage

- Open a video: the "Open video…" button / `Ctrl+O`, dropping a file onto the window, a click on a file in the
  history or a path on the command line: `af-video-player movie.mkv`.
- Subtitles are chosen with the `CC` button on the panel: main (original) and secondary (translation). Embedded
  subtitles of a video are first exported to external files — in the same "Subtitles" dialog.
- The interface is in English.
- `Space` shows the list of cues (the video pauses), `Space` or `Ctrl+Space` again continues playback.
  A click on the video or `Ctrl+Space` only pauses, without the list. In the list: the translation on the left, the time and the original
  on the right; a click on a word — dictionary, a mouse selection — dictionary for the phrase, the "G" button —
  translation of the cue, a click on the time — jump, a right click — mark.
- Keys: `←`/`→` — seek 5 s, `↑`/`↓` and the wheel over the video — volume, `M` — mute, `A` — audio track, `S` — subtitles on the
  video, `N` — next file in the folder, `F` or a double click — full screen, `Ctrl+H` — back to the start page,
  `Ctrl+,` — settings. The keys also work with a Russian or Ukrainian keyboard layout.
- Settings and history are stored in `%LOCALAPPDATA%\af-video-player` (Windows), `~/.config/af-video-player`
  and `~/.local/share/af-video-player` (Linux), `~/Library/Preferences/af-video-player` and
  `~/Library/Application Support/af-video-player` (macOS).
- The player does not register file associations: to open videos by a double click, choose `af-video-player`
  in "Open with" of the file manager.

## Build

Requires CMake ≥ 3.21, a C++20 compiler, Qt ≥ 6.8 (modules qtbase, qtdeclarative, qtsvg), libmpv and FFmpeg.

**Windows** (Visual Studio 2022 Build Tools with the C++ workload):

```powershell
./scripts/fetch-deps-windows.ps1          # libmpv and FFmpeg into deps/
$env:QT_ROOT_DIR = "C:/Qt/6.11.3/msvc2022_64"
cmake --preset windows
cmake --build --preset windows
ctest --preset windows
```

To run from the build folder, add `$env:QT_ROOT_DIR/bin` to `PATH`. Portable archive:
`./scripts/package-windows.ps1 -Version 1.0.0` → `dist/`. A local portable folder without an archive:
`./scripts/package-windows.ps1 -Local` → `dist/windows/af-video-player/` (the previous one is replaced).
After a change of `packaging/icons/af-video-player.svg`, `./scripts/make-icons.ps1` regenerates the icons of all
platforms.

**Linux** (Debian/Ubuntu): `sudo apt install cmake ninja-build pkg-config libmpv-dev libavformat-dev
libavcodec-dev libavutil-dev libswscale-dev` and Qt ≥ 6.8 (from the distribution or the official installer).
**macOS**: `brew install cmake ninja pkg-config mpv ffmpeg qt`. Then:

```bash
export QT_ROOT_DIR=/path/to/Qt/6.x/gcc_64   # if Qt is not a system one
cmake --preset unix
cmake --build --preset unix
ctest --preset unix
```

Packages: `scripts/package-linux.sh 1.0.0` (AppImage), `scripts/package-macos.sh 1.0.0` (zip with `.app`).

Release: when a `v*` git tag is pushed, GitHub Actions builds the packages for the three OSes and publishes them in
GitHub Releases.
